Moonfin Books Preview 2 adds in-app sheet-music search and requests, clearer ebook/audiobook discovery, and a simpler series/anime detail view.

- Search sheet music from a verified Mutopia catalog and the Internet Archive IMSLP collection. Request a score, follow its import status, open it in the app once Jellyfin indexes it, or save the PDF to your device. Requires the matching Moonbase Books 2.3.1.101 plugin and its score importer.
- Search books by title and optional author. Exact German titles rank ahead of translations and summaries; release choices show format and language, prefer the correct work, and limit requested releases to German and English. Downloads still require an explicit choice.
- `watch.tiedemann.art` no longer focuses Kids by default. Multiple seasons appear directly on series/anime pages; cast, crew, studios and recommendations remain available under More Actions. Library order is Filme, Serien, Anime, Bücher, Hörbücher, Noten, Filme Kids, Serien Kids.

The build is a personal fork of official Moonfin, shared for others who want the same features. It is not an official upstream or app-store release. Check `SHA256SUMS` and `SOURCE_REVISIONS.txt` for the exact package and source commits. iOS/tvOS IPAs are unsigned; macOS is ad hoc signed and Windows packages have no publisher signature. Device coverage is described in `docs/BUILD_STATUS.md`.
